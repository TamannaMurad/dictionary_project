# 📖 Dictionary App

A simple and responsive dictionary web application that allows users to search for any English word and instantly view its **definitions**, **synonyms**, and **antonyms**.

The application fetches real-time data from the **Free Dictionary API** using **Axios** and displays the results in a clean and user-friendly interface.

---

## ✨ Features

- 🔍 Search for any English word
- 📖 Display multiple definitions
- 🔹 Display synonyms (duplicates removed)
- 🔸 Display antonyms
- 🔊 Listen to pronunciation
- 🌐 Fetch live data from the Free Dictionary API
- ⚠️ Handle invalid word searches gracefully
- 📱 Responsive and modern user interface
